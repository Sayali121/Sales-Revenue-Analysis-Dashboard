# Sales & Revenue Analysis Dashboard

Interactive dashboard using Streamlit and Plotly with 1,200 synthetic sales records.

## Files
- dashboard.py — application
- sales_data.csv and sales_data.xlsx — dataset
- insights.pdf — findings
- requirements.txt — dependencies

## Run
1. Install Python.
2. Run `pip install -r requirements.txt`
3. Run `streamlit run dashboard.py`

Filters: region, category, date range. KPIs: revenue, order count, units, average order value. Charts: monthly trend, regional revenue, top products, category share.

Dataset is synthetic and intended for demonstration only.
